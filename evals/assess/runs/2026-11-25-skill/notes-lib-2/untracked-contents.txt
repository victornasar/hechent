=== CONTRIBUTING.md
# Contributing to notes-lib

Thanks for helping out. notes-lib is a small library of helpers for creating notes.

## Requirements

- Node.js 18 or newer. Tests use the built-in `node:test` runner, so there are no dependencies to install.

## Project layout

```
src/notes.js         library code (exports createNote)
test/notes.test.js   tests, run with node:test
```

## Running the tests

```sh
npm test
```

This runs `node --test`, which finds and runs the files under `test/`.

## Making a change

1. Create a branch from `main`.
2. Make your change in `src/`.
3. Add or update tests in `test/` to cover the new behavior. A bug fix should include a test that fails without the fix.
4. Run `npm test` and make sure every test passes.
5. If the change affects how the library is used, update `README.md`.
6. Open a pull request against `main` that says what changed and why.

## Code style

- CommonJS modules (`require` / `module.exports`), matching the existing code.
- Keep functions small and validate inputs explicitly. For example, `createNote` throws when the title is missing.

## Commit messages

Write short messages in the imperative mood. A type prefix such as `docs:`, `fix:`, or `feat:` is welcome. For example:

```
docs: describe notes
fix: trim whitespace from note bodies
```
